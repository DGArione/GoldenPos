QR Ordering

Each table has a QR code (print it from Floor). Guests scan it to open the menu, order from their phone, and the order goes to the kitchen and shows in Payment under that table.

The address a guest's phone uses to reach this POS — your till's network address, or a public domain if you expose it. Leave blank to use the current address.
When off, QR orders wait in Online Orders for a staff member to accept first.

Printing

A print agent is a tiny helper that runs on the till computer and drives your thermal printer directly — so KOTs and receipts print without the browser's print dialog (which drops you out of full-screen). Leave this off to keep using browser printing. A reference agent ships in the print-agent/ folder of the app.

Used by the Print button on Floor → table QR. Leave empty to use the browser print window.

Storage & Backups

Choose where Golden POS keeps its data (the database, bill logs) and where it saves backups. Use a drive that is always connected to this computer. A USB stick that gets unplugged will stop the POS.

System Maintenance

💾 Backup & Restore

Download a complete snapshot of your data (menu, orders, inventory, users, settings) as a JSON file you can keep safe. For a full byte-for-byte backup, copy the server's data/pos.db file while the app is stopped — this in-app export is a quick, portable copy.

Tip: schedule this weekly. Keep a copy off the computer (USB drive or cloud). Restore replaces ALL current data with the uploaded file — use with care.
